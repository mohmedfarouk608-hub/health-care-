# health-care-


The project covers the complete data analysis workflow, starting from data preparation and exploratory analysis to machine learning, model evaluation, and interactive visualizatio.

## 📌 Project Overview

The main objective of this project is to extract meaningful insights from healthcare data and build predictive models that can support data-driven decision making.

The project includes:

- Data Cleaning & Preparation
- Exploratory Data Analysis (EDA)
- Statistical & Business Analysis
- Feature Engineering
- Machine Learning Modeling
- Model Evaluation
- Interactive Power BI Dashboard
- Streamlit Deployment

## 📊 Power BI Dashboard

The Power BI dashboard provides an interactive overview of healthcare operations and patient characteristics.

### Dashboard Pages

**1. Healthcare Overview**
- Total Patients
- Total Billing
- Average Billing per Patient
- Average Length of Stay
- Admissions Trend Over Time
- Patients by Medical Condition
- Admissions by Admission Type
- Test Results Distribution

**2. Medical & Test Results Analysis**
- Total Doctors
- Total Hospitals
- Normal Test Results %
- Average Patient Age
- Average Length of Stay by Medical Condition
- Patient Distribution by Gender
- Medical Condition & Test Results Analysis

**3. Financial & Operations**
- Billing Analysis
- Hospital Performance
- Insurance Provider Analysis
- Admission and Financial Trends

## 🤖 Machine Learning

Machine learning models were developed to identify patterns in the healthcare data and generate predictions based on relevant patient features.

Different models were evaluated using appropriate performance metrics to identify the best-performing approach.
